# Jeu de Cartes à Gratter Crypto

## Description
Un jeu simple et rapide de cartes à gratter où les joueurs peuvent miser en crypto et gagner des multiplicateurs variés, allant du remboursement de la mise jusqu'à un jackpot x50,000.

## Fonctionnalités :
- Grattage interactif des cartes.
- Système aléatoire pour générer les gains.
- Multiplicateurs allant de x2 à x50,000.
- Interface simple et immersive.
